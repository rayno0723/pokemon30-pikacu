# ⚡ 皮卡丘 30 周年卡牌清點與交換工具

一個專為皮卡丘 30 周年紀念卡牌（No.01~30）打造的線上清點與交換紀錄網頁。

👉 **[點此直接開啟線上工具](https://rayno0723.github.io/pikachu-30th/)**

### 🌟 功能特點
- 📊 **清點與統計**：記錄 1~30 號卡牌持有狀態，自動計算收集百分比與總卡數。
- 🔢 **數量模式**：支援切換「數量編輯模式」，可記錄每張卡牌擁有的確切數量。
- 🔄 **自動標記交換**：持有張數 2 張以上自動標示為「可交換」。
- 🖼 **一鍵匯出圖卡**：直接產出高畫質 PNG 圖卡，方便貼至社群/LINE 交換。
- 💾 **自動離線儲存**：無需註冊，瀏覽器會自動記錄您的集卡進度。
