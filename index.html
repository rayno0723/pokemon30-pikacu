📖 使用說明與功能介紹

🎨 卡牌狀態說明

  • 需求 X 張：數量為負數（例如 -1），代表需要徵求該張卡牌。
  • 未收集：數量為 0，代表尚未擁有。
  • ✓ 已收集：數量為 1，自己留存收藏。
  • 🔄 可交換：數量為 2 以上，多出的卡牌可拿去交換。

👆 操作方式

  • 一般模式：直接點擊卡牌格子，可快速進行「未收集 ➔ 已收集 ➔ 可交換」的循環切換。
  • 數量編輯模式：點擊「🔢 開啟數量編輯模式」按鈕後，可用 + / - 按鈕精確調整張數，亦可點選成負數來表示需求張數。

📤 分享與交換

  • 🖼 匯出圖片：自動將目前的卡牌進度繪製成一張畫質清晰的 PNG 圖卡並下載，方便貼至 LINE 或社群平台。
  • 📋 複製文字：產生格式化好的交換文字檔，自動整理出多出可換與缺少需求的號碼。

💡 溫馨提示：您的所有資料皆會自動儲存在個人瀏覽器中，重新整理或關閉網頁後紀錄也不會遺失！
